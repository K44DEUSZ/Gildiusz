# Zgłaszanie problemów bezpieczeństwa

Nie publikuj tokenów Discorda, danych członków ani informacji pozwalających wykorzystać podatność w publicznym issue. Jeśli GitHub udostępnia w tym repozytorium prywatne zgłoszenie podatności, użyj tej funkcji. W pozostałych przypadkach publiczne zgłoszenie powinno zawierać jedynie ogólny opis i prośbę o ustalenie prywatnego kanału kontaktu.

Zgłoszenie techniczne powinno określać wersję Gildiusza i Node.js, wymagane uprawnienia, oczekiwane zachowanie i minimalne kroki odtworzenia. Używaj serwera testowego i fikcyjnych danych.

Wczesna seria 0.x nie ma ustalonego okresu wsparcia. Poprawki trafiają na main; przed wdrożeniem sprawdź zgodność bazy i aktualną dokumentację.
